# 14. Requirement Compliance

The acceptance mapping is maintained in `docs/requirement-checklist.md`; the
live project state is maintained in `docs/project-status.md`. The final
evidence supports TCP control, filesystem-root safety, RDT reliability,
Active/PASV transfers, integrity checks, cancellation/cleanup, concurrency,
and CLI/logging. Release gates that require team decisions remain explicitly
marked as in progress rather than inferred from code review.
