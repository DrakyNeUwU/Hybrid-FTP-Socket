# Planning Status

`docs/project-status.md` là nguồn trạng thái dự án duy nhất.

- Cập nhật tiến độ Done / In progress / Deferred tại đó.
- Dùng `docs/requirement-checklist.md` để kiểm tra acceptance trước nộp.
- Dùng `../weekly-plans/tuan-cuoi-ngay-tai-phan-chia.md` để điều hành task,
  owner, deadline, blocker và evidence mỗi tối.

Không tạo thêm status snapshot trong thư mục này để tránh mâu thuẫn.
